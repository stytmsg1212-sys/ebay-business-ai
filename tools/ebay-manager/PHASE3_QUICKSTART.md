## 動作確認チェックリスト

### Step 1: eBay API認証テスト
```
目的: API認証情報が正しいか確認
手順:
  1. 設定タブに認証情報を入力
  2. 「💾 設定を保存」
  3. eBay連携タブで「📊 レポート表示」クリック

期待結果:
  {
    "total_ebay": 0,
    "with_source": 0,
    "status_breakdown": {}
  }
  (最初は0件でOK - 同期がまだだから)
```

### Step 2: 出品取得テスト
```
目的: eBay APIから実際に出品を取得できるか確認
手順:
  1. 「🔄 eBay出品取得・同期」 をクリック
  2. 処理完了を待つ（APIの速度次第で数秒～数十秒）

期待結果:
  「✅ 同期完了: XX件同期, YY件マッチ」

トラブル:
  - "❌ eBay API認証情報が不足しています"
    → 設定タブで4つとも入力されているか確認

  - "❌ 同期エラー: ..."
    → API認証情報が正しいか確認
    → eBay APIステータスページで障害確認
```

### Step 3: SKUマッチング確認
```
目的: eBay出品と仕入元在庫がSKUでマッチしているか確認
手順:
  1. 「🔄 eBay出品取得・同期」 をクリック
  2. テーブルの「Source Status」 列を確認

期待結果:
  - SKUが表示される → eBay側でSKU設定済み
  - Source Status に値が入っている → マッチ成功

トラブル:
  - Source Status が全て "unknown"
    → monitored_items に該当SKUが未登録
    → 「📡 在庫監視」タブから追加
```

### Step 4: 在庫ステータス反映テスト
```
目的: 仕入元の在庫状態がeBay側に反映されているか確認
手順:
  1. 「📡 在庫監視」タブで「▶ 全件チェック」実行
  2. 「🔗 eBay連携」タブで「🔄 eBay出品取得・同期」 実行
  3. テーブルの「Source Status」 を確認

期待結果:
  - available: 仕入元で在庫あり
  - unavailable: 仕入元で在庫なし
  - not_found: 仕入元ページなし

確認ポイント:
  - Last Sync が現在時刻に更新されている
```

## よくある質問 (FAQ)

### Q: 「同期完了: 0件同期, 0件マッチ」 と表示されました
**A**: eBay出品にSKUが設定されていません。
- eBay出品管理画面でSKUを設定してください
- SKU設定後、再度同期ボタンをクリック

### Q: Source Status がすべて "unknown" です
**A**: 仕入元の在庫監視データがまだです。
- 「📡 在庫監視」タブで「▶ 全件チェック」を実行
- その後、再度同期を実行

### Q: API呼び出しにはコストがかかりますか？
**A**: いいえ。eBay Trading API の GetMyeBaySelling は無料です。

### Q: 出品を自動更新できますか？
**A**: Phase 3では同期（データ読み込み）のみ。更新は Phase 3.2で実装予定。

### Q: 1000件以上の出品がある場合は？
**A**: 現在のコードは自動ページネーション対応。全件取得可能。

## トラブルシューティング

### エラー: "eBay API認証情報が不足しています"
```
原因: 4つの認証情報のいずれかが空
対処:
  1. 設定タブを確認
  2. 4つすべて入力されているか確認
  3. 「💾 設定を保存」をクリック
  4. ブラウザをリロード（F5）
```

### エラー: "eBay API error: Connection timeout"
```
原因: eBay API サーバーが応答していない
対処:
  1. eBay API ステータスページを確認
  2. 数分待機して再試行
  3. 時間帯を変更して試行（深夜は避ける）
```

### エラー: "Failed to sync listing XXX: ..."
```
原因: 特定の出品でデータ形式エラー
対処:
  1. ログファイルで詳細確認
  2. その出品のSKUを確認
  3. 大半の出品は同期されているはず（スキップされた1件のみエラー）
```

### eBay出品一覧が空です
```
原因:
  1. eBay側に出品がない
  2. 出品があるがSKUが未設定
  3. API同期がまだ実行されていない
対処:
  1. eBay出品管理画面でSKU設定を確認
  2. 「🔄 eBay出品取得・同期」 ボタンをクリック
```
