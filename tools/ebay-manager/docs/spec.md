# eBay Manager 仕様書

## 概要

**プロダクト名**: eBay Manager
**目的**: eBay 越境 EC 物販ビジネスの利益計算、在庫監視、ランク管理を統合した Streamlit ツール
**対象ユーザー**: eBay セラー（日本から米国向け DDP 販売）
**現在のバージョン**: Phase 4（本番運用中）

---

## 非機能要件

### パフォーマンス
- ページ初期ロード: < 10秒
- タブ切り替え: < 2秒
- eBay 同期: < 30秒（API 待機含む）
- 全件チェック（33サイト）: < 5分（平均 9秒/サイト）

### セキュリティ
- API キーは .env ファイルで管理（コードに直書きしない）
- 入力値のサニタイズ（SQL インジェクション対策）
- XSS 対策（Streamlit が自動対応）

### 信頼性
- エラーメッセージは日本語で表示
- エラー発生時もアプリケーションはクラッシュしない
- 部分的失敗（例：1 サイトのスクレイピング失敗）時は続行

### スケーラビリティ
- 出品数 500～1000 件での動作確認
- 監視サイト数 33 → 50 サイトへの拡張を想定

## UI/UX 仕様

### レイアウト
- Streamlit `st.tabs()` で タブインターフェース
- 各タブは `st.columns()` で マルチレイアウト
- `st.dataframe()` でテーブル表示
- `st.expander()` で 詳細情報の折り畳み

### ユーザーフロー
```
1. 利益計算
   入力 → 計算実行 → 費用内訳・利益表示 → 出品判定

2. 在庫監視
   仕入元 URL 登録 → 全件チェック → 在庫状態表示 → Discord 通知

3. eBay 連携
   eBay API 設定 → 出品取得 → ランク自動更新 → ランク分布表示

4. 競合監視
   ライバル検知 → 価格比較 → 確認・無視アクション

5. 設定
   API キー設定 → 手数料カスタマイズ → 保存
```

## 既知の制限事項

- **HitCount（View 数）**: eBay Trading API では取得不可 → REST API が必要（v2.0 計画）
- **eBay 送料バグ**: システムで検知可能だが、自動修正はできない（手動対応必須）
- **スクレイピング精度**: サイト HTML 変更時は設定調整が必要
