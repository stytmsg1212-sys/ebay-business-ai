9. 定時実行タスク詳細

Stepタスク処理内容入力出力所要時間
1eBay同期 eBay APIで全出品取得→DB upsert→ランク計算 eBay APIebay_listings 479件 ~8分
2在庫チェック 仕入先URLをSeleniumで巡回→在庫判定 sourced_items CSVinventory_results JSON ~40分
3在庫アラート 在庫有→無に変化した商品を検出 前回結果との差分アラートリスト <1秒
4仕入先候補 在庫切れ商品の代替仕入先を選出 在庫切れリスト候補リスト ~1分
5メール取得 Gmail APIでeBay関連メール抽出 Gmail APIメール件数・詳細 ~10秒
6リサーチ 新商品候補の調査（基準ファイル参照） criteria.mdresearch/notes/ ~2分
7ライバル検出 同一商品を出品するJapanセラーを検知 eBay APIライバルリスト ~5分
8データ統合 JSON→DB突合（SKU変換+在庫ステータス） 各種JSONmonitor.db更新 <1秒
9価格最適化 競合価格比較→価格改定提案 ebay_listings提案リスト ~2分
10売上追跡 Gmailの売上通知→DB記録 Gmailsales_history ~10秒
11ニュース確認 AI/eBay関連ニュース取得 Webニュースサマリー ~1分
合計所要時間: 約60分/回 × 4回/日 = 約4時間/日の自動処理
在庫チェックが全体の約67%を占める（Selenium巡回のため）
