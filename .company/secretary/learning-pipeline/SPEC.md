# 秘書室 Learning Pipeline（YouTube 動画学習システム）

## 役割

YouTube の動画コンテンツから **構造化された学習資料** を自動生成するパイプラインエージェント。

eBay コンサル動画などから、リサーチ部門が活用可能な知識を抽出し、Markdown 形式で蓄積します。

---

## 責務

1. **動画 URL 解析**
   - YouTube URL からメタデータを取得
   - 動画タイトル、説明、長さを確認

2. **コンテンツ抽出**
   - 公開字幕がある場合は取得
   - 字幕がない場合は動画説明欄から要点抽出
   - コメント欄の有用な情報を補足

3. **知識構造化**
   - Claude で内容を要約・分類
   - キーポイント、ノウハウ、実践方法を抽出
   - 他部署との関連性を特定

4. **資料生成**
   - `research/learning/YYYY-MM-DD-{topic}.md` を生成
   - リサーチ部門が即座に活用可能な形式

5. **品質評価**
   - 抽出内容の完全性・正確性を確認
   - ビジネス価値のある洞察が含まれているか判定

---

## 入力形式

```
YouTube URL: https://www.youtube.com/watch?v=Wfz-gdWcItM

対象部署: リサーチ（eBay知識の蓄積）
```

---

## 処理フロー

```
入力: YouTube URL
    ↓
1. メタデータ取得
   - 動画タイトル・説明・長さ
   - チャンネル情報
   ↓
2. コンテンツ抽出
   - 自動生成字幕 or 説明欄テキスト
   - キーフレーム・概要抽出
   ↓
3. Claude による要約・構造化
   - 主要なポイント抽出
   - eBay ビジネスへの適用方法
   - 実践的なノウハウ
   ↓
4. Markdown 文書化
   - 見出し・箇条書き・表で整理
   - リサーチ部門への連携
   ↓
5. 品質評価
   - 内容の完全性確認
   - ビジネス価値の判定
   ↓
出力: research/learning/YYYY-MM-DD-{topic}.md
```

## YouTube 動画の処理方法

### パターン1: 字幕がある場合
1. YouTube の自動生成字幕取得
2. 時間ごとにセクション化
3. 各セクションを要約
4. Claude で全体の構造化

### パターン2: 字幕がない場合
1. 動画説明欄から概要取得
2. コメント欄の有用な意見を抽出
3. 関連リンクから補足情報取得
4. Claude で内容をまとめる

### パターン3: 複雑な動画（複数テーマ）
1. タイムスタンプごとにテーマ分割
2. 複数の Markdown ファイルに分割出力
3. インデックスファイルで統括


### 処理
```
1. メタデータ取得
   → タイトル: "eBay 2024 年の価格戦略とリサーチ方法"
   → 長さ: 42 分
   → 字幕: ✅ あり

2. コンテンツ抽出
   → 0:00-5:00 : はじめに・概要
   → 5:00-15:00 : 価格調査の手順
   → 15:00-30:00 : 競合分析の方法
   → 30:00-42:00 : 実践例・Q&A

3. Claude で要約
   → 「価格調査は 3ステップ（1.相場取得 2.競合分析 3.利益率計算）」
   → 「月１回の市場調査で価格改定の効率化」
   → など

4. Markdown 生成
   → research/learning/2026-04-07-ebay-pricing-strategy.md

5. 品質評価
   → スコア: 4.6/5 ✅
   → リサーチ部門へ即座に連携可能
```

### 出力
```markdown
# eBay 価格設定戦略

## 概要
2024年の eBay マーケットプレイスにおいて、効果的な価格設定と市場調査は売上向上の鍵。
本動画では、プロセラーの視点から実践的な価格調査手法を解説。

## 3ステップ価格調査方法
1. **相場取得** (5-10分)
   - eBay Advanced Search で同一商品を検索
   - Sold listings でフィルタ
   - 過去30日の成約価格を記録

2. **競合分析** (10-15分)
   - TOP 5-10 のライバルセラーを特定
   - 価格、説明文、画像数を比較
   - 差別化ポイントを洗出す

3. **利益率計算** (5分)
   - 送料・手数料・仕入原価を差引
   - 目標利益率 15-20% を確保
   - 市場価格と利益率のバランスを調整

## 実践例
- iPhone 13 128GB の相場：USD 450-550
- ライバルの平均価格：USD 480
- 推奨出品価格：USD 490 (利益率 18%)

## リサーチ部門への反映
→ 毎週金曜日に市場調査スケジュール化
→ 新商品リサーチ時の標準手順に組み込み
```

## パイプラインの定期運用

### スケジュール
- **毎週火曜日**: 新しい YouTube 動画を指定して学習実行
- **毎月末**: 月間の学習内容を総括・インデックス化

### 蓄積される知識
```
research/learning/
├── 2026-04-07-ebay-pricing-strategy.md
├── 2026-04-14-ebay-competitive-analysis.md
├── 2026-04-21-ebay-customer-service.md
├── 2026-04-28-ebay-shipping-optimization.md
└── INDEX.md （月間学習内容の目次）
```

### リサーチ部門への連携
- リサーチ Generator が新しい学習内容を参照
- 市場調査の手法をアップデート
- eBay 知識部門が学習内容を知識化
