# 2026-04-08 学び・気づき

## 🎯 YouTube 動画学習パイプライン実装から学んだこと

### 1. ローカル Whisper の強力さ
- **実装**: FFmpeg + openai-whisper で 100% オフラインで文字起こし可能
- **品質**: 15,000+ 文字の日本語転写が高精度（実際の会話内容が正確に抽出）
- **コスト**: API費用ゼロ（初期セットアップのみ）
- **課題**: CPU処理が若干遅い（10分強の動画で10分の処理時間）

### 2. FFmpeg PATH 注入の重要性
- **問題**: Whisper が内部で ffmpeg を呼び出すが、PATH にない場合に FileNotFoundError
- **解決**: Python の `os.environ['PATH']` に直接 FFmpeg パスを追加
  ```python
  ffmpeg_path = r"C:\ffmpeg\bin"
  if ffmpeg_path not in os.environ.get('PATH', ''):
      os.environ['PATH'] = ffmpeg_path + os.pathsep + os.environ.get('PATH', '')
  ```
- **教訓**: 外部ツール依存時は起動時に PATH 設定を確認する

### 3. ファイル名の扱い（日本語に注意）
- **問題**: yt-dlp の出力テンプレートに `%(title)s` を使うと、日本語のファイル名が Windows temp で不安定
- **解決**: `%(ext)s` のみで固定名 `audio.webm` に統一
  ```python
  'outtmpl': str(Path(self.temp_dir) / 'audio.%(ext)s')
  ```
- **教訓**: 一時ファイルは言語非依存の名前を使う

### 4. YAML フロントマッター + Markdown の相性
- **学び**: メタデータと内容を分離できるため、機械処理が容易
- **実装**: 動画ID、URL、チャンネル、タイムスタンプを YAML に格納
- **効果**: 後で自動分類・グループ化がしやすい

### 5. API キー設定の段階的実行
- **発見**: Whisper（ローカル）と Claude（API）の組み合わせで、片方が失敗しても部分的に動作
- **シナリオ**:
  - API キーなし → Whisper 文字起こし + テンプレート出力
  - API キーあり → Whisper 文字起こし + Claude 要約・スコア評価
- **利点**: 段階的な機能追加・テストが可能

## 🏢 エージェント・ハーネス設計の本質

### 動画から学んだポイント

**ハーネス = AI エージェントの制御手綱**

従来のプロンプトエンジニアリング → コンテキストエンジニアリング → **ハーネスエンジニアリング** という進化の中で：

1. **プランナー**: 仕様書・条件を定義
2. **ジェネレーター**: 実装・実行
3. **エバリュエーター**: テスト・品質判定・フィードバック

この 3 つを自動ループさせることで、人間の承認を最小化しながら、高品質な成果物を自動生成できる。

### eBay ビジネスへの応用イメージ

- **リサーチの自動化**:
  - Planner が「Nike の Dunk Low の相場調査」を指定
  - Generator が価格データ収集・分析実行
  - Evaluator が結果の妥当性を検証・フィードバック

- **出品文の自動化**:
  - Planner が「SEO最適化で CTR 上昇を狙う」方針を策定
  - Generator が出品文を英語生成
  - Evaluator が eBay ガイドライン準拠・可読性をチェック

## 📝 実装上の重要な気づき

### システム初期化の重要性
- FFmpeg パスの自動注入 → **スクリプト起動時に確認する**
- UTF-8 エンコーディング設定 → **Windows PowerShell での出力文字化け防止**
- 依存ライブラリの確認 → **import 失敗を graceful に処理**

### エラーハンドリングの工夫
- API キーが未設定の場合 → テンプレート出力にフォールバック
- Whisper 文字起こし失敗 → エラーログを詳細に記録
- ファイル保存失敗 → 親ディレクトリの自動作成

$env:ANTHROPIC_API_KEY = "sk-ant-..."
