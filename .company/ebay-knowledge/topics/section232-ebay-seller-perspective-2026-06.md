# Section 232 関税 — MonoHonpo セラー視点の構造分析 (2026-06)

**確信度: 高(制度構造・HS章判定)/ 中(CPaSS の請求見え方 = user 実体験で要照合)**
**前提**: user 実体験「複数発送・Section232 請求は1件のみ」を一次事実として所与。DB 確認済の売上120件構成・customs_requests 16件も所与。出典: 2026-06-02 research-brain(Opus 4.8)分析。

## 1. なぜ請求が1件だけだったか — 構造的説明

結論: **MonoHonpo の主力商品が、HS章レベルで Section 232 派生品リストの「外」に位置するか、「閾値の壁」で課税対象外になるため**。3つのフィルタを順に通過する必要があり、主力商品はどれかで脱落する。

### フィルタ①: そもそも派生品リスト(Annex I-A/I-B/III)に HS が載っているか

Section 232 は「金属を含む全商品」ではなく、**指定 HTS コードのみ**が対象(Annex I-A=Ch72-74/76 純金属、I-B=Ch84-87 の指定派生品)。リスト外の HS は金属を含んでいても**永久に非該当**。

| MonoHonpo 主力 | 代表 HS章 | 派生品リスト | 判定 |
|---|---|---|---|
| 計測器 (HIOKI/Keysight/Mitutoyo/YOKOGAWA/DENSO) | **Ch90** (90.30 測定器, 90.31 等) | **リスト外** | **非該当(構造的)** |
| 電子書籍リーダー (ONYX BOOX) | **Ch85** (8543/8471系) | 該当 HS でない | 非該当 |
| オーディオ (FOSTEX/maxell) | Ch85 (8518 スピーカー, 8519/8523) | 該当 HS でない | 非該当 |
| 色鉛筆 (Holbein) | **Ch96** (9609) | リスト外 | 非該当 |
| ソフトウェア (VOCALOID) | Ch85/無体 | リスト外 | 非該当 |
| Leica プリズム | Ch90 (9015 測量機器) | リスト外 | 非該当 |
| **炊飯器 (Netsuken NV-25)** | **Ch85 (8516.60.40)** | **I-B 掲載** | **該当 → 課税(1件)** |

**核心**: Ch90(計測器・光学・測量)は Section 232 派生品リストにほぼ載っていない。MonoHonpo の売上ボリュームゾーンが Ch90 計測器であることが、「請求1件」の最大の構造要因。

### フィルタ②: Ch85/84 内でも「掲載 HS」と「非掲載 HS」が割れる(最重要・誤解しやすい点)

「Ch85 = 電子 = 全部対象」ではない。**同じ Chapter 85 でも、派生品リストに HS が個別指定されている品目だけが対象**:

- **掲載(該当)**: 8516(電熱家電・炊飯器)、8504.31-33(変圧器)、8501(モーター)、8415(エアコン)、8418(冷蔵)、8517.71/8544(電線・部品)
- **非掲載(非該当)**: 8543(電子機器でその他)、8471(自動データ処理 = e-reader系)、8518(スピーカー)、8519/8523(音響・記録媒体)

→ MonoHonpo のオーディオ(8518系)・電子書籍リーダー(8471系)は**Ch85 だが非掲載 HS** なので非該当。一方で FOSTEX **トランス(8504.31)** とモーター類は**掲載 HS** に当たるため、これだけは候補になる(後述§2)。

### フィルタ③: 金属含有15%閾値(Ch84-87 のみに効く)

派生品リスト掲載 HS(Ch84-87)でも、**非米国産金属(鉄/アルミ/銅)が重量で15%以下なら Section 232 はゼロ**(2026 Web一次情報確認)。各金属ごとに独立判定。

- 炊飯器 NV-25: steel 47% ≥15% → **課税**(KB ケーススタディで実証、$199.50)
- 仮に小型トランスで筐体プラ主体・金属<15% → 掲載 HS でも**非課税**になりうる

**注意(Ch72-74/76 は閾値なし)**: 金属鍋(7323)・ストーブ(7321)等の純金属製品は閾値ルールが効かず**自動課税**。MonoHonpo が今後これらを扱うと確実に直撃。

## 3. CPaSS DDP の実務メカニクスと「請求された1件」の見え方

CPaSS(eBay公式 DDP 配送)は **予測関税 ~15% を出荷時に徴収** → 実関税が確定したら **到着30日後に差額を自動精算(超過分返金 / 不足分は原則 eBay 吸収または追加なし)**。

- **非該当の主力商品(95%)**: 予測15%徴収 → 実関税は MFN(計測器は多くが Free〜数%)+ IEEPA top-up で15%前後。予測 ≈ 実 or 予測超過 → 30日後に返金。CPaSS は計測器では「やや取りすぎ → 後で戻る」。
- **該当した1件(炊飯器)**: 実関税が **25%** で予測15%を10pt超過。CPaSS の予測徴収だけでは不足し、差額が後から請求 or DDP 精算で売主負担として顕在化したはず。user の体感と整合。

> 確信度・中: CPaSS の不足差額を eBay が吸収するか売主請求するかの正確な挙動は、user の実明細(該当1件の DDP 内訳)と照合して確定すべき。**残リスク**: ここは制度資料より user 実データが真実。

## 4. 利益計算(W212)への示唆

**結論: 提案設計(デフォルト15% + Section232該当フラグで該当カテゴリのみ25/50%)が正しい。95%全件に Section232 buffer を載せるのは過剰 = 機会損失。**

### 推奨ロジック(W212 per-listing 実関税)

```
1. HS章で一次フィルタ:
   - Ch90 / 96 / 8471/8518/8519/8523 等(非掲載) → Section232 = 0、IEEPA 15% のみ
2. 派生品リスト掲載 HS(8516/8504/8501/8415/8418/8544/8708/Ch72-74/76)→ section232_flag = True
3. section232_flag=True かつ:
   - Ch72-74/76 → 50%(I-A、閾値なし自動)
   - Ch84-87 → 金属重量比率を確認:
       ≥15% → 25%(I-B)、IEEPA は exempt(ただし8708自動車部品はIEEPA重複=例外)
       <15% → Section232=0、IEEPA 15%
   - Annex III 該当(産業機械) → 15%(~2027-12)
4. デフォルト(該当判定が付かない全件)= IEEPA reciprocal 15%
```

**機械化の現実解**: 金属重量比率の自動取得は困難なので、**該当HS(Ch84-87掲載)に当たった時だけ user に「金属比率≥15%か」を確認するフラグ**を立てる(95%は確認不要、5%だけ人間判断)。K1 Simplicity に合致。

## 5. eBay 出品・価格戦略への含意

### 攻めるべき(強み = 関税薄)
- **Ch90 計測器(HIOKI/Keysight/Mitutoyo/YOKOGAWA)**: Section232 構造的ゼロ + 日本ブランドの信頼性で高単価。**本丸として伸ばすべき**。
- **文具(Holbein)・オーディオ(FOSTEX非トランス品)・ソフト(VOCALOID)**: 関税薄・VeRO 低リスク・軽量。

### 該当カテゴリの扱い
- **金属鍋・ストーブ(Ch72-74/76, 50%自動)**: **原則避ける**。閾値逃げが効かず50%固定、DDP で粗利消滅リスク最大。
- **電熱家電(8516, 25%)**: **buffer込みで選別的に攻める**。高単価なら成立余地あり。粗利率30%未満かつ該当なら user 承認待ち(自動 BLOCK しない=機会損失回避)。
- **トランス/モーター(8504/8501)**: 金属<15%なら非課税の余地 → HS と重量で個別判定。

### 戦略総括
MonoHonpo の現構成は **「Section232 をほぼ踏まない HS ポートフォリオ」**になっており、計測器中心の事業特性が関税防御として機能している。攻め筋は計測器・精密機器の深掘り。家電・金属調理器具への横展開だけ HS事前判定をゲートにすべき。

## red flags / 注意点
- **規制業務の最終責任は人間**: HS分類・金属比率判定・Section232 該当の最終確定は **現地通関士(customs broker)に委ねる**。本分析は値付け buffer の意思決定支援であり、自動採用してはならない。
- **High-value($500+)**: 出品前に customs broker classification 確認。
- **CBP CSMS は2-4週で改訂**: §2 の HS 一覧は 2026-06 時点。値付け固定化前に CBP CSMS 再確認。
- **CPaSS 事後精算の正確な挙動**(§3)は user 実明細と要照合 = 確信度中。
