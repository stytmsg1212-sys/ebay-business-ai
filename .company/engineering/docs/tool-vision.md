# eBay自動化ツール構想

## 目指すシステム全体像

eBay自動化システム + 統計蓄積 + AI秘書 を統合したツール。

**核心**: 「見る・探す・比べる・判断する」の大部分を肩代わりする。

---

## 設計思想

1. 人が毎回作らなくていい入力を増やす
2. 人が入力する項目数を減らす
3. `run_daily` までの前準備を減らす
4. 人が判断すべき部分だけを残す
5. 条件を満たすなら実行までツールに任せる

**方針**: 完全自動より「効果の高い半自動」を先に実装する。

## 実装時の注意事項

### 仕入れ先の優先順位
- 実装しやすさではなく、**実際によく使う仕入れ先を優先**する
- Yahoo!ショッピングが実装しやすくても、主力がメルカリ・ヤフオクならそちらを先に

### 競合比較の実装
- 比較は必ず **商品価格 + 送料の総額** で実装する
- 単純な価格比較では正確な競合判定ができない

### listing_mode の判定実装
- SKUに `stock` を含む → `in_stock`
- それ以外 → `no_stock`
- eBay側SKUを基準にする
