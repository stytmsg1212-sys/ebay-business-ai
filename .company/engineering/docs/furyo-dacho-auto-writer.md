# 古物台帳自動書き込みシステム 設計書

## 概要

Gmail MCPで仕入れメールを読み取り、Google Sheetsの古物台帳に自動書き込みするシステム。

## 設計・方針

### 対象プラットフォーム
| プラットフォーム | 購入通知メール差出人 | 台帳ファイル |
|----------------|-------------------|------------|
| ヤフオク | shopping-proorder-master@mail.yahoo.co.jp / auction-master@mail.yahoo.co.jp | ヤフオク |
| Yahoo!フリマ | payment-master@mail.yahoo.co.jp | ヤフオク |
| メルカリ | no-reply@mercari.com | メルカリ |
| ラクマ | noreply@fril.jp | ラクマ |
| その他ECサイト | 各ショップ | その他 |

### 支払いカード自動判定ロジック

**プラットフォーム固定ルール（優先）**

| プラットフォーム | カード | 判定方法 |
|----------------|--------|---------|
| メルカリ | セゾンカード | 固定（確認不要） |

**ヤフオク・Yahoo!フリマ（金額照合）**

Yahoo!かんたん決済メール受信時、±60分以内のカード利用通知メールと金額を照合する。

| カード | 差出人ドメイン | シート名 |
|--------|-------------|---------|
| PayPayカード（メイン） | paypay-card.co.jp | Paypayカード |
| 楽天カード | rakuten-card.co.jp | 楽天カード |
| セゾンカード | メール通知なし | — |
| 判定不能 | — | ユーザーに確認 |

**ラクマ（固定ルール）**

| プラットフォーム | カード | 判定方法 |
|----------------|--------|---------|
| ラクマ | 楽天カード | 固定（確認不要） |

**その他**（要確認、実績が溜まり次第固定ルール化）

## 詳細

### 書き込みフロー

```
1. Gmail MCP: 仕入れメール検索（ヤフオク/メルカリ/ラクマ）
2. メールから抽出するデータ:
   - 取引日（メール受信日時）
   - 品名
   - 仕入金額（税込・送料込）
   - 仕入先名称
   - 商品ID（オークションID等）
3. カード判定: 同時刻前後のカード利用通知と金額照合
4. 書き込み先の決定:
   - 台帳ファイル（ヤフオク/メルカリ/ラクマ/その他）
   - シート（Paypayカード/楽天カード/セゾンカード/銀行振込）
   - 管理番号（次の空き番号を自動採番）
5. Google Sheets API で書き込み
6. mail-check-log.md を更新
```

### Google Sheets 設定（2026年アクティブ）

設定ファイル: `engineering/docs/google-sheets-config.md` 参照

### 古物台帳 カラム構成

| 列 | 項目 | 自動入力 | 備考 |
|----|------|---------|------|
| B | 管理番号 | ✅ 自動採番 | 既存の空き番号を使用 |
| C | 取引日 | ✅ | メール受信日 |
| D | 品名（古物） | ✅ | メール件名から抽出 |
| E | 数量 | ✅ | 基本1 |
| F | 仕入金額（税込） | ✅ | 送料込み合計 |
| G | 仕入先氏名・名称 | ✅ | ストア名 or 個人出品者 |
| H | 商品ID | ✅ | オークションID |
| I | 仕入先住所 | ✅ | 「ヤフオク取引」等 |
| J | 本人確認方法 | ✅ | 「非対面（ヤフオクアカウント・取引画面確認）」 |
| K | 備考 | ✅ | 送料・決済ID等 |
