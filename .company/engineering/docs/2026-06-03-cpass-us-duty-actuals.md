## 含意 (money-direct)

1. **MonoDeck の duty_rate=20% は実績の約2倍** → 全US商品で表示利益が過小 → 黒字品の機会損失。実績に合わせ **10〜11%** が妥当。
2. **W212 の Section232 per-listing 率 (25〜55%) は OC 実請求と乖離**。OC DDP 経由では Section232 該当品も flat 10% しか請求されていない (少なくとも過去90日実績)。25〜55%を入れると当該品の利益を大幅過小評価。
3. ただし「**推定**米国関税」表記 = OC が税関実額のリスクを負い flat 10% で請求している構造。OC のポリシー変更/true-up が起きれば Section232 品は跳ね上がる **残リスク**あり (user 判断事項)。

### ★★ true-up メカニズム (官報・最重要)

OC 公式: 「最終的な関税額は CBP の実課税額に基づき確定。**過払い→返金 / 不足→追加請求**」。
= OC の 10% は **推定**であり、CBP 実額との差は事後精算される。**Section232品で CBP 実額>10% なら理論上「追加請求」がありうる** (user 懸念の核心)。

### 実際の「追加支払い」メール (実態)

1. **FedEx「貨物に対する輸入手数料の支払金額」** (FedEx**直送**分、OC SpeedPAKとは別チャネル):
   - 889911532475 (2026-04) = **JPY 3,000** / 888776896344 (2026-02) / 888304875298 (2026-02、支払確認あり) / 886756968684 (2025-12)。
   - 6か月で約4件、各 ¥3,000 程度の少額。FedEx が立替えた関税を seller に請求。
2. **FedEx「米国/EU 未払い関税」** (2026-05): EU(ルクセンブルク)向け **DDU** 貨物で **取引先(buyer)が未払い** → 60日後に荷送人(TOYOTASUMI)へ転嫁の警告。請求 133.97 (EUR想定)。US-DDPではない。
3. **OC SpeedPAK (US-DDP) 分の Section232 追徴 = 観測されず**。例: 炊飯器 $798 (8516.60.40 = Section232 I-B) は OC が 10.1%=¥12,682 を inline 請求し配送完了、後日の25%追徴(~¥30,000規模)は Gmail に存在しない。

### ★ IEEPA 関税還付 (返金) が進行中

- OC「IEEPA 関税還付の進捗」(2026-05-27) + FedEx「IEEPA関税返金」(2026-05-15/18)。
- IEEPA 無効化 → CBP が還付ツール CAPE 運用開始 → OC が通関業者経由で **対象貨物の還付申請を順次提出中**。
- 還付額/時期は CBP 審査待ち。**= 15% 時代 (2025/10〜2026/2) に払った IEEPA 関税が一部戻る可能性** (seller の資金繰りにプラス)。

### 結論 (Gmail 調査)

- **OC SpeedPAK (US向け主力チャネル) の関税は原産国別 flat 推定 (現行 JP=10%)、inline 課金、Section232 含め追徴は実態として未発生**。
- 追加支払いは (a) FedEx直送の少額立替 (¥3,000×数件)、(b) EU-DDU の buyer 未払い転嫁 — いずれも US-DDP 主力フローの話ではない。
- **残リスク (官報明記)**: OC の 10% は推定で、CBP 実額 > 10% なら「追加請求」がありうる (特に Section232)。ただし過去実績では発生していない。逆に過払い分 (IEEPA 15%) は還付進行中。
