# eBay Manager QA 基準リスト

## 概要

このドキュメントは、eBay Manager（Streamlit ツール）の開発における **品質基準を明文化** したものです。

**目的:**
- 曖昧な「品質」の定義を具体化
- 開発者（ジェネレーター）と評価者（エバリュエーター）の間で「合格」の定義を共有
- 自動テストループを実装可能にする

**スプリット契約**: 以下の全項目を満たすことが「開発完了」です。

---

## A. 機能テスト（必須）

### A-1: アプリケーション起動
| 項目 | 内容 | テスト方法 | 合格条件 |
|------|------|---------|---------|
| **テスト名** | アプリ起動テスト | `streamlit run app.py` 実行後、ブラウザで localhost:8501 にアクセス | HTTP 200、h1 要素が存在 |
| **タイムアウト** | 10秒以内 | — | ページロード時間 < 10s |
| **エラーなし** | コンソールエラーなし | ブラウザコンソール確認 | JavaScript エラー 0件 |

### A-2: UI 要素の表示
| 項目 | 内容 | テスト方法 | 合格条件 |
|------|------|---------|---------|
| **タブ数** | 5個のタブが表示 | タブボタンをカウント | `button[role='tab']` が 5個以上 |
| **タブ名** | 「利益計算」「在庫監視」「eBay連携」「競合監視」「設定」 | タブのテキストをチェック | 全て表示 |
| **メインタイトル** | "eBay Manager" が見える | h1 をチェック | h1 = "eBay Manager" |

### A-3: タブ機能
| 項目 | テスト内容 | テスト方法 | 合格条件 |
|------|----------|---------|---------|
| **タブ切り替え** | クリックで各タブに遷移可能 | 各タブをクリック | 全 5 タブがクリック可能かつ内容が変わる |
| **eBay連携タブ** | eBay タブ固有のコンポーネントが表示 | eBay タブで「eBay出品取得・同期」ボタンが見える | ボタンが 1 個以上存在 |

### A-4: フォーム入力
| 項目 | テスト内容 | テスト方法 | 合格条件 |
|------|----------|---------|---------|
| **数値入力** | st.number_input で値を入力可能 | 利益計算タブで input に "12345" を入力 | 値が反映される（input.value == "12345"） |
| **テキスト入力** | st.text_input で値を入力可能 | 入力フィールドにテキストを入力 | 値が反映される |
| **チェックボックス** | st.checkbox で状態が切り替わる | チェックボックスをクリック | 状態が変わる |

### A-5: ボタン機能
| 項目 | テスト内容 | テスト方法 | 合格条件 |
|------|----------|---------|---------|
| **クリック可能** | button が clicked 可能 | 任意のボタンをクリック | クリック後、アクション実行または状態変化 |
| **無効ボタンなし** | 全ボタンがクリック可能 | 5 個のボタンをテスト | 3 個以上がクリック可能 |
| **ボタン数** | 最低 10 個のボタンが存在 | button 要素をカウント | button >= 10 |

### A-6: エラー処理
| 項目 | テスト内容 | テスト方法 | 合格条件 |
|------|----------|---------|---------|
| **エラーメッセージなし** | 赤いアラートが表示されない | `[data-testid='stAlert']` で赤色を確認 | エラーアラート 0 件 |
| **警告メッセージ** | 警告は表示されてもOK（黄色） | — | — |
| **ページクラッシュなし** | ページが白くなっていない | 視認確認 | コンテンツが表示されている |

## テスト合格の定義

### ✅ 合格（Development Complete）
```
- Phase A 全項目: 合格
- Phase B 全項目: 合格
- 新しいエラーが導入されていない
→ リリース可能
```

### ⚠️ 条件付き合格
```
- Phase A: 合格
- Phase B: 1-2 項目が FAIL（ただし軽微）
→ ユーザーに報告してから進める
```

### ❌ 不合格（Needs Revision）
```
- Phase A: 2 個以上 FAIL
- または既存機能が壊れている
→ 修正が必須
```
