### 3.4 robocopy 除外パターン

Chrome / Terapeak browser profile は **path embed が内部 state にある** → 別 path に move で corruption リスク。**移行対象から除外、新 path で空 profile 再生成**:

```powershell
robocopy `
  "C:\Users\gucch\projects\claude" `
  "C:\Users\gucch\projects\claude" `
  /MIR /COPYALL /R:3 /W:5 /MT:16 `
  /XD ".chrome_cdp_profile" `
  /XD ".terapeak_browser_profile" `
  /XD "__pycache__" `
  /XD ".pytest_cache" `
  /XD "_archive" `
  /XF "monitor.db-wal" `
  /XF "monitor.db-shm"
```

**user 影響**: Terapeak OAuth は新 path 初回起動時に user 再ログイン 1 回必要 (§10 で明示)
