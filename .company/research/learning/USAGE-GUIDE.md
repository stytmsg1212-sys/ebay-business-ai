# リサーチ部門 - YouTube 学習内容の活用ガイド

秘書が抽出した YouTube 学習内容（eBay コンサル動画など）を、リサーチ業務に組み込む方法です。

---

## 📚 学習内容の所在

秘書が処理した YouTube 動画から抽出された学習内容は、ここに保存されます：

```
research/learning/
├── YYYY-MM-DD-ebay-pricing-strategy.md
├── YYYY-MM-DD-ebay-customer-service.md
├── YYYY-MM-DD-ebay-shipping-optimization.md
└── INDEX.md （全学習内容の目次）
```

---

## 🔄 活用フロー

### リサーチ Generator の視点

```
新しいリサーチ依頼を受ける
  ↓
「research/learning/ に関連資料があるか確認」
  ↓
ある場合：
  → 学習内容を参考に高度な分析手法を適用
  → 動画で紹介されたテクニックを実践
  → より正確・詳細なリサーチ実施
  ↓
リサーチ結果を出力
```

### 実践例 1: eBay 価格設定戦略の学習内容を活用

**状況**: 「iPhone 13 128GB の相場を調べて」というリクエスト

```
1. research/learning/YYYY-MM-DD-ebay-pricing-strategy.md を参照
2. 学習内容から「3ステップ相場調査」を確認
   - Advanced Search で同一商品検索
   - Sold Listings でフィルタ
   - 過去30日のデータ集計
3. この3ステップに従ってリサーチ実施
4. 「TOP 10 競合分析」も追加で実施
5. 相場データ + 競合情報 + 推奨価格をまとめて出力
```

**出力例**:
```markdown
## iPhone 13 128GB 相場調査結果

### 相場データ（過去30日）
- 最低: USD 380
- 中央値: USD 480
- 最高値: USD 680

### 競合分析（TOP 10）
[セラー名] [価格] [強み]
seller1  USD 500  大量出品
seller2  USD 520  高評価
...

### 推奨出品価格
USD 490（相場 USD 480 + 差別化要因を考慮）

### リサーチ方法
✅ Advanced Search で 50 商品を確認
✅ Sold Listings フィルタで成約データ取得
✅ 30日間のトレンド分析を実施
```

## 📋 学習内容の参照方法

### リサーチ Generator が新しいタスクを受ける

```python
# 1. リサーチ依頼内容を確認
リクエスト: "中古スマートフォンの eBay 相場を調べてください"

# 2. research/learning/ ディレクトリを確認
learning_files = {
    "ebay-pricing-strategy": "相場調査の方法",
    "ebay-competitive-analysis": "競合分析のテクニック",
    "ebay-customer-service": "カスタマー対応のベストプラクティス",
}

# 3. 関連する学習内容を参照
relevant_files = ["ebay-pricing-strategy", "ebay-competitive-analysis"]

# 4. 学習内容に従ってリサーチを実行
for file in relevant_files:
    学習方法 = read_learning_content(file)
    apply_technique_to_research(学習方法)

# 5. 高度なリサーチ結果を出力
```

A: リサーチ Evaluator に報告してください。修正版を秘書に依頼します。

### Q: リサーチと関係ない動画の学習内容が保存されています
A: research/learning/INDEX.md で関連性をフィルタリングしてください。
